# HaTrix — English & Japanese Vocabulary Learning Platform

**Live Demo:** https://hatrix-sigma.vercel.app/

HaTrix is a web-based vocabulary learning platform that helps users learn and review English and Japanese vocabulary through multiple interactive practice modes.

## Features

- **Flashcards:** Review vocabulary using digital flashcards.
- **Multiple Choice:** Test vocabulary knowledge through quick quizzes.
- **Matching Cards:** Match words with their meanings.
- **Spelling Practice:** Improve vocabulary recall by typing words.
- **Listening Practice:** Practice vocabulary recognition through listening.
- **Comprehensive Practice:** Review vocabulary through a combined assessment.
- **Vocabulary Management:** Select vocabulary sets, filter words by learning status, and customize practice sessions.
- **Practice History:** Track previous practice sessions and review scores.

## Tech Stack

- React
- JavaScript
- HTML
- CSS

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm

### Installation

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm start
   ```

4. Open http://localhost:3000 in your browser.
